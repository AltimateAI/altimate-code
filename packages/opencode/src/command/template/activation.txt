dialog — you would never see this template fire in that context. If you
ARE seeing it, the invocation happened through a non-TUI surface
(`altimate run`, ACP client, headless server, `--print` mode, an
automation runner) where the dialog cannot render.

and ask the user to pick one, then continue from their answer.

  I've reopened the activation prompt. Since there's no interactive
  dialog here, pick one of the three by name and I'll take it from

  1. Connect data — point me at your dbt project, or run

command — the user pays for the choice with a keystroke here, same as
the TUI dialog.
