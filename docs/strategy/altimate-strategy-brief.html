06 — The Category Play

Create the category. Own the search term.

Don't say
  • "AI-native data engineering" — backlash is real, Soda owns it
  • "AI-powered" anything — noise, every vendor says this
  • "Agentic data platform" — Ascend.io's term, means SaaS
  • Lead with features — leads with technology, not outcome
Do say
  • "data engineering harness" — unclaimed, timely, precise
  • Lead with the outcome: reliable, trusted, production-grade
  • Write the blog posts that define the category
  • Reference Anthropic + OpenAI + Fowler — they legitimized "harness"
The dbt playbook — how they created "analytics engineering"
  1. Identified a real gap that practitioners felt but couldn't name
  2. Named the role / category — published it, owned the term
  3. Built the open-source tool that defined the role
  4. Created community: Slack, conference (Coalesce), certification
  5. Monetized collaboration and governance — never the CLI
  6. Result: $100M+ ARR, 50K+ teams, category leader in 6 years
The category we're creating
data engineering harness

The infrastructure layer that wraps around AI agents and human workflows to make data engineering reliable in production. Same concept Anthropic, OpenAI, and Fowler described — applied to data. Nobody owns this term. We will.
